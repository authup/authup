Query Reference ​

The queryable vocabulary of every entity, one section per schema. Read Query Language first: it defines the parameters, the operators and the rules under which a key here is honoured or silently dropped.

Generated from release 1.0.0-beta.64, registry fingerprint e724e285f003ffb606eeacb2d59c4bc9882e4e5dfa0ca12d32ada2d8dd34f2fe. GET /schemas reports both values back under meta, so a deployment that has drifted from this page can be recognised without diffing anything.

Every list below is the static upper bound. A caller is additionally subject to its own permissions: a relation it may not read is stripped from the include, and a gated column is redacted, both without an error.
